# 模式：修订与审稿回复（revision and response）

目标：先修推理，再修文字；把审稿意见逐条落到动作与稿件位置，交付可执行的回复包。

## 输入

- 审稿意见原文（逐字保留，不改写、不合并、不删减）。
- 修订事实：改了什么、补了什么数据、做了哪些新分析。
- 作者必须坚持的判断与对应的证据。
- 目标期刊的修订格式要求（字数、图件、补充材料、回复信结构）。

## 流程（依据 references/revision-and-response.md）

1. 意见分类：事实错误、证据不足、解释分歧、写作与格式、超出范围。
2. 建跟踪表：每条意见 → 动作（接受并改 / 部分接受 / 有理有据地不同意）→ 稿件位置 → 需要的作者输入。缺失事实标 `AUTHOR_INPUT_NEEDED`，不要替作者编。
3. 推理修复优先：每节的任务、claim → evidence → boundary、沙漏结构、主题句；再做语法与语域。
4. 只改被标出的段落，除非结构性改动已获确认；改动处加粗或给出行号对照，附 change log。
5. 写逐点回复信：引用意见、给出动作、指明位置、给证据；语气合作、证据优先、不防御。
6. 交付：策略摘要、跟踪表、回复信、修改清单、风险提示。

## 验收

- 每条意见都有唯一去向，没有「已在文中修改」这类无定位回复。
- 不同意的地方给出证据与边界，而不是语气更强的断言。
- 新数据与新分析在回复信中与正文口径一致（n、检验、P 值、方向）。
- 双语修订时两种语言同时加粗改动，术语与证据强度一一对应。
- 不承诺未做的实验；未来工作明确标注为未来。
