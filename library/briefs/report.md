# 模式：学术报告（progress / group / final report）

目标：把已有结果整理成一份在固定时长内读得懂、经得住追问的报告：结论先行、证据可追溯、计划与结果严格分开。

## 输入

- 场合与时长：组会、季度进展、结题、答辩预演、项目评审。
- 听众与他们的前置知识：同领域、交叉领域或评审专家。
- 报告要回答的 2–3 个问题（不要超过三个）。
- 可用证据：图、表、分析、统计、失败实验。
- 未完成部分的真实状态：卡在哪、下一步判据是什么。
- 保密边界：哪些内容不能出现在共享材料里。

## 流程

1. 先定结论：最多三条，每条一句话，写清对象、关系与条件。写不出就回到证据。
2. 每条结论配证据：哪张图、哪个统计、哪个对照；缺口单列，不要用文字掩盖。
3. 定结构：现状与问题 → 本期做了什么 → 结果是什么 → 离目标还差多少 → 下一步（时间 + 判据）。
4. 统一图件：复用图件模式（figure set）的规格；报告页与论文图不能混用两套字号。
5. 写讲稿要点：每页一句主张 + 三个支撑；预判 5–8 个会被问的问题并准备数据解答。
6. 交付：报告大纲、逐节要点、图表清单、预判问答、待补数据清单。

## 验收

- 每一节只有一个结论，且该结论在标题里就能读到。
- 每个数字有出处（哪次分析、哪份数据、哪个 n）。
- 计划写成「将要 + 判据 + 时间」，绝不表述为已完成结果。
- 失败与负结果保留，用描述性语句写（「62/84 个位移为负」「调整后 95% 区间包含 0」），不写成道歉。
- 一页一个视觉重心；无意义的装饰性图表删掉。
