# Notice and attribution

NatSci-Writing-skills is an author-maintained production system assembled from three sources.

## 1. Author project standards

The Nature/Science manuscript and figure standards, project figure geometry and colour contracts, structural-figure (Baker) standard remain the author's project material.

## 2. NatSci corpus analysis

Measured writing and figure statistics come from a locally collected Nature/Science corpus (868 records). The corpus is not redistributed; only aggregate statistics and public exemplar identifiers appear in the skills.

## 3. nature-skills (open source, Apache-2.0)

Design patterns and selected structural ideas were adapted from the nature-skills project by Yuan Yizhe and contributors, licensed under the Apache License 2.0:

https://github.com/Yuan1z0825/nature-skills

Adapted material has been rewritten, reorganized and translated for this package; it is not a verbatim redistribution of the upstream skill files. The Apache-2.0 license text shipped with this bundle is the root `LICENSE` file (the upstream repository keeps it at `LICENSES/Apache-2.0.txt`).

## 4. Scope

The author's original content and project-specific standards are not relicensed by this notice beyond the repository license. Users are responsible for verifying journal requirements and any third-party permissions before submission.
